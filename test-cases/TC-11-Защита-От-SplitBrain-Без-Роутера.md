# TC-11: Защита от Split-Brain без роутера (Предохранитель №1)

## 1. Паспорт тест-кейса
- **Идентификатор**: `TC-11`
- **MMD-диаграмма**: [`mmd/ВосстановлениеПослеПаденияМастерРезерв.mmd`](../mmd/ВосстановлениеПослеПаденияМастерРезерв.mmd)
- **Цель**: Проверить работу сетевого предохранителя №1 сторожа деградации: если одиночный узел включается в изолированном сегменте (нет связи ни с соседом, ни с внешним маршрутизатором), разблокировка кворума категорически блокируется во избежание захвата VIP в изолированном сегменте сети.
- **Объекты проверки**:
  - Предохранитель №1 в `/usr/local/sbin/cluster-degraded-unblock.sh`.
  - Комбинированная проверка доступности шлюза (ICMP ping + L2 arping).
  - Блокировка команды `pcs quorum unblock`.
  - Сохранение ресурсов в безопасном состоянии `Stopped`.

---

## 2. Предусловия
1. `node2` выключен.
2. На `node1` сымитирован обрыв внешнего кабеля к шлюзу `192.168.1.1` (отключен патч-корд `eth0` или заблокирован трафик).
3. Установлен ускоренный тестовый таймаут (20 секунд).

---

## 3. Шаги выполнения и ожидаемые результаты

### Шаг 1. Имитация изоляции и старт одиночного узла node1
**Команда на `node1`:**
```bash
# Блокируем доступ к роутеру:
iptables -I OUTPUT 1 -d 192.168.1.1 -j DROP

# Запускаем скрипт сторожа:
/usr/local/sbin/cluster-degraded-unblock.sh || echo "Сторож завершился с кодом $?"
```

---

### Шаг 2. Контроль блокировки в логах сторожа
**Команда на `node1`:**
```bash
journalctl -t cluster-watchdog -n 20 --no-pager
```
**Ожидаемый результат:**
- Сторож фиксирует:
  ```text
  cluster-watchdog: ОШИБКА: Маршрутизатор (192.168.1.1) недоступен ни по ICMP, ни по ARP! Разблокировка отменена.
  ```
- Скрипт аварийно завершается с кодом возврата `1`.
- Команда `pcs quorum unblock` **не выполняется**.

---

### Шаг 3. Контроль состояния кластера
**Команда на `node1`:**
```bash
corosync-quorumtool -s
pcs status
```
**Ожидаемый результат:**
- `Quorate: No`.
- Все ресурсы (`vip`, `pgsql`, `core-app-stack`, `daemon-svc`) остаются в состоянии **`Stopped`**.
- Риск Split-Brain и работа в слепой изоляции полностью исключены!

---

## 4. Восстановление исходного состояния
```bash
iptables -D OUTPUT -d 192.168.1.1 -j DROP
```

---

## 5. Что делать при отклонении
1. Если сторож разблокировал кворум при отключенном роутере:
   - Проверить список `ROUTER_IPS` в `/etc/default/ha-cluster`. Убедиться, что скрипт действительно опрашивает именно реальный шлюз, а не локальный адрес хоста.
