# pgsqlms-ha

Обёртка PAF: обязательное физическое сохранение исходной ветки, затем pg_rewind
с fallback на pg_basebackup. Полное SQL-восстановление из pg_waldump не обещается.

Актуальные гарантии, ограничения, параметры и оставшиеся работы:
[HA-AUTO-RECOVERY.md](HA-AUTO-RECOVERY.md).

setup-node.sh устанавливает агент; configure-ha.sh создаёт новый ресурс с
ocf:heartbeat:pgsqlms-ha. Эти изменения файлов не меняют уже работающий кластер.
Изменение существующего CIB выполняется отдельно после стендовых испытаний.
Fencing/quorum в этой доработке не менялись.

Статус: локальные тесты пройдены; production-готовность не подтверждена.
