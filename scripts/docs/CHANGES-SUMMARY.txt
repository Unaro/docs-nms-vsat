Изменения программного восстановления

pgsqlms-ha: обязательный проверенный физический архив до pg_rewind; при ошибке
перезапись запрещена. Ненадёжная генерация SQL через xmin удалена. Команды
исполняются аргументами без bash -c, применены timeout, проверка system_identifier,
фиксация источника, блокировка, идемпотентный start, обработка ошибок переносов.
Старые PGDATA и архивы не удаляются. Внешние WAL/tablespaces пока запрещены.

setup-node.sh: install -m 0755, проверка PAF, GRANT для control-функций;
автоматическое ослабление SELinux/AppArmor удалено.
configure-ha.sh: pgsqlms-ha и увеличенные бюджеты операций.
generate-ha-config.sh: отдельные параметры таймаутов восстановления.
validate-pgsqlms-ha.sh: исправлены счётчики set -e и ряд небезопасных подсказок.
tests/test-pgsqlms-ha.py: 5 локальных тестов; реальные БД/кластер не затрагиваются.

Fencing/quorum не менялись. Production-готовность не заявляется.
Ограничения и оставшиеся задачи: docs/HA-AUTO-RECOVERY.md.
